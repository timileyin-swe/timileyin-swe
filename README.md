## Selected projects

### [Job Application API](https://github.com/timileyin-swe/job-application-api)

A FastAPI service for recording applications and following them from application to offer. SQLite stores the records, and GitHub Actions runs the API tests on pull requests.

**Try it locally:** Open `/docs`, add two applications, and move one to `interview`. Then call `GET /reports/status-counts` to see how the totals change. [Setup and examples](https://github.com/timileyin-swe/job-application-api#readme) · [Test runs](https://github.com/timileyin-swe/job-application-api/actions/workflows/api-tests.yml)

### [Python Expense Tracker](https://github.com/timileyin-swe/python-expense-tracker)

A command-line tool for recording expenses, reviewing monthly spending, and exporting records to CSV. It stores amounts as whole kobo so spending totals stay exact.
